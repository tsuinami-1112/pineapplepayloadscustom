# CamScout signature file.  One rule per line:  TYPE|CAT|LABEL|PATTERN      # note
#   TYPE    OUI VENDOR VENDOR_WEAK VENDOR_MODULE VENDOR_ENDPOINT SSID SSID_WEAK
#   CAT     SECURITY DOORBELL BABY ACTION DASH DRONE BODYCAM ALPR NVRKIT MIXED IOTMOD ENDPOINT
#   LABEL   on-screen tag, ^[A-Z0-9][A-Z0-9-]{1,9}$, unique (a label may not be reused by another TYPE)
#   PATTERN last field so a regex | is safe. OUI = AA:BB:CC (24-bit) or AA:BB:CC:D (28-bit) or AA:BB:CC:DE:F (36-bit).
#           Every other TYPE is a case-insensitive POSIX ERE matched against the vendor text from
#           /lib/hak5/oui.txt (VENDOR*) or against the beaconed SSID (SSID*).
# Weights are fixed by TYPE in payload.sh (OUI/VENDOR 45, VENDOR_WEAK 20, VENDOR_MODULE 0, VENDOR_ENDPOINT -25,
# SSID 45, SSID_WEAK 15); contributors add rows, not numbers.  Lines starting with # are ignored; a bad TYPE,
# CAT or LABEL is reported on screen at start ("sig line N skipped") and the rest of the file still loads.
# Verified = checked against the IEEE MA-L/MA-M registry or a published setup guide, Oct 2026.
# Unverified rows ship commented out; uncomment after you have seen the device yourself.
